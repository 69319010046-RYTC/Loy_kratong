# 🏮 Loy Krathong 3D (ลอยกระทง 3D)

เว็บลอยกระทง 3 มิติริมแม่น้ำเจ้าพระยา (Chao Phraya River Loy Krathong Experience) สร้างด้วย **Three.js** และ Web Audio API พร้อมเอฟเฟกต์แสง สี เสียง คลื่นน้ำ และบรรยากาศงานวัดริมแม่น้ำเจ้าพระยาอย่างสมจริง

![Loy Krathong 3D Preview](https://img.shields.io/badge/Three.js-r165-black?logo=three.js)
![Status](https://img.shields.io/badge/status-active-brightgreen)

## ✨ จุดเด่นของผลงาน (Features)
- 🪷 **กระทงเอกประธานมุมกล้องหน้า**: กลีบใบตองพับจีบวิจิตรศิลป์ 2 ชั้น ดอกดาวเรือง กล้วยไม้ บัวสีชมพู เทียนสีเหลืองพร้อมเปลวไฟเต้นระยับ และธูป 3 ดอกจุดไฟปลายแดง
- 🏛️ **ทัศนียภาพริมแม่น้ำเจ้าพระยา**:
  - บันไดท่าน้ำหินแกรนิตทอดยาวลงสู่แม่น้ำ
  - โคมไฟคลาสสิกทรงกลมสีทองอบอุ่น
  - สายไฟประดับงานวัดขึงตลอดแนวท่าน้ำ
  - ร้านค้าขายของกินไทยโบราณ (ผัดไทย ลูกชิ้นปิ้ง ขนมครก ข้าวเหนียวมะม่วง ชาไทย) พร้อมพ่อค้าแม่ค้าและผู้คนเดินเที่ยวงาน
- ⛵ **เรือสำราญล่องแม่น้ำเจ้าพระยา**: เรือไม้ทรงไทยประดับไฟนีออน LED และหลังคาจั่วช่อฟ้าใบระกา ล่องตามกระแสน้ำ
- 🌉 **สะพานพระราม 8 สีทองอร่าม**: เสาสะพานทรงตัว Y คว่ำและสายเคเบิลสีทองเรืองแสงทอดข้ามแม่น้ำ
- 🌕 **พระจันทร์เต็มดวงและทะเลดาว**: ดวงจันทร์ส่องแสงนวลพร้อมดวงดาวระยิบระยับบนท้องฟ้าราตรี
- ✍️ **การมีส่วนร่วม (Interactivity)**:
  - ช่องพิมพ์เขียนคำอธิษฐานและกดปุ่ม "ปล่อยกระทง"
  - เอฟเฟกต์เสียงน้ำกระเพื่อมและเสียงพลุเฉลิมฉลอง (Web Audio API)
  - โหมดหมุนและเลื่อนชมวิวอัตโนมัติ (Cinematic Tour) และควบคุมด้วยเมาส์หรือคีย์บอร์ด (W/A/S/D / ลูกศร)
- ⚡ **ความลื่นไหลระดับ 60 FPS**: ปรับแต่ง Shader, Bloom และ Water reflection ให้ทำงานได้อย่างลื่นไหล

## 🚀 วิธีเปิดใช้งาน (Getting Started)
เพียงเปิดไฟล์ `index.html` บนเว็บเบราว์เซอร์ (Google Chrome, Safari, Edge, Firefox) ได้โดยตรง ไม่ต้องลงโปรแกรมหรือติดตั้ง dependencies ใดๆ เพิ่มเติม!

```bash
# Clone the repository
git clone https://github.com/<username>/Loy_kratong.git

# Open index.html directly
open index.html
```
